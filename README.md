🚀 Praticando JavaScript — Exercício 1: Divisão de Números

📌 Sobre o projeto

Este projeto foi desenvolvido como exercício prático de JavaScript, com o objetivo de aplicar conceitos fundamentais de lógica de programação, variáveis, funções, operações matemáticas e retorno de valores.

A aplicação solicita ao usuário dois números por meio do comando "prompt()", realiza a divisão através de uma função personalizada e apresenta o resultado utilizando "alert()".

🎯 Funcionalidades

- Entrada de dois números utilizando "prompt()".
- Processamento da divisão por meio de uma função.
- Utilização de parâmetros e retorno de valores ("return").
- Exibição do resultado com "alert()".

🛠️ Tecnologias utilizadas

- HTML5
- JavaScript

📚 Conceitos praticados

- Declaração de variáveis ("var").
- Criação e chamada de funções.
- Parâmetros e argumentos.
- Operadores aritméticos.
- Retorno de resultados.
- Interação com o usuário.

🎓 Objetivo

Fortalecer os conhecimentos em JavaScript e desenvolver o raciocínio lógico por meio de exercícios práticos, construindo uma base sólida para projetos mais avançados em desenvolvimento de software.
